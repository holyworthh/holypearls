## What was done
1. **Deleted** nine one-off design scripts at the repo root (`audit_domains.py`, `audit_screenshots.py`, `check_content.py`, `check_key_screenshots.py`, `detailed_audit.py`, `download_photos.py`, `inspect_slices.py`, `organize_ui_refs.py`, `pencil_client.js`) and `captured_assets.json`. They had hard-coded `C:\Users\ASUS\…` paths and nothing referred to them.
2. **Deleted** 24 images in `apps/web/public/pen/` that no page uses: `generated-` 11, 34–41, 43, 44, 46, 48, 49, 53–56, 58, 84, 88–90, 92. The category page builds image names from numbers, so the check covered `PHOTOS` in `categories/[slug]/page.tsx` and `directory.module.css` as well as file names.
3. **Removed** the `geist` package from the web app. Both apps load fonts with `next/font/google`.
4. **One money formatter.** `displayMoney` moved from `apps/api/src/orders/orders.ts` to `packages/contracts/src/money.ts`, so the API and the browser share it.
   - In the API, `orders.ts`, `tracking.ts`, `payments.ts`, `quotes/customer.ts` and `quotes/quotes.ts` import it from contracts. `quotes.ts` also loses `formatMoney`, which only called `displayMoney`.
   - `naira()` in `packages/web-kit/src/money.ts` now takes an optional currency and calls `displayMoney`. The local copies in `Configurator.tsx`, `GarmentConfigurator.tsx`, `ProductCard.tsx` and `products/[slug]/page.tsx` use it.
5. **`displayMoney` in API notes.** `sales/delivery-price.ts` and `shipments/courier-booking.ts` used their own `naira()`, which went through floating point and always showed ".00".
6. **One slug schema.** `slugSchema` is exported from `packages/contracts/src/catalogue.ts`.
   - The content and configuration schemas use it, and the content schema still trims first.
   - The five `[slug]` pages in the web app call `slugSchema.safeParse(slug).success` in place of their own `validSlug`.
7. **One SHA-256 helper.** `configuration/drafts.ts` and `projects/projects.ts` use `sha256` from `identity/customers.ts`, which they already imported. `shipments/reorder.ts` uses `deviceHash` from `sales/cart.ts`, which it already imported.
   - `deviceHash` is now `sha256`.
   - `drafts.ts` can't import from `cart.ts`, because `cart.ts` already imports `drafts.ts`.
8. **One `toSlug` in admin**, in `apps/admin/src/app/(shell)/format.ts`, used by the category, content and new-product editors. It is the content editor's version, the most careful of the three: it normalises accents and never ends with a hyphen after cutting to 80 characters.
9. **Date helpers.**
   - `quotes/customer.ts` uses `day` from `quotes/quotes.ts`.
   - In the web app, `ProofView` and `QuoteView` share `day` from the new `apps/web/src/lib/format.ts`. The order page keeps its own, because it leaves out the year.
10. **Removed** `apps/web/src/lib/api.ts`, `money.ts` and `catalogue-labels.ts`, which only re-exported `@holypearls/web-kit/*`. 38 imports in 32 files now name web-kit directly.
11. **Removed** the two Stage 4.1 board PDFs, about 31 MB. The Stage 4.2 board and the Pen file replace them, and the Stage 4.1 review's PDF line says so. They stay in git history, so clones don't get smaller.

About 445 lines of code (net), one dependency and about 32 MB of files are gone.

## Visible changes
- **Product cards and the product page "From" price** show kobo when a price has some (₦3,937.50, not ₦3,937), and USD prices show `$`. Before, these cut kobo off. All seeded list prices are whole naira (checked in a seeded database: 0 of 12 price rules have kobo), so every seeded screen renders as before.
- **Delivery and courier wording** drops ".00" on whole amounts (₦4,500 rather than ₦4,500.00). This is the staff audit summary, the shipment history note and the "delivery priced" customer email. Every other email already used `displayMoney`.
