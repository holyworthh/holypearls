### Data (migration 0042)

- **`brand_assets`:** `organization_id`, `name`, `kind` (LOGO, PRINT, EMBROIDERY, GUIDELINES, PACKAGING), `version`. Brand assets are organization-wide (TECH-03 §7: "explicitly organization-wide").
- **`brand_asset_versions`:**
  - Columns: `asset_id`, `number`, `file_id`, `status`, `review_note`, `reviewed_by_staff_id`, `reviewed_at`, `uploaded_by_user_id`.
  - Unique (`asset_id`, `number`), and one file per version.
  - Versions are never deleted or overwritten: uploading V5 adds a row and V4 is untouched (B2B-FR-023).
- **Files:** a new file purpose `BRAND_ASSET` (design files: PDF, AI, SVG, PNG or JPEG; 50 MB; private).

### Statuses (TECH-01 §4)

- **Normal path:** PROCESSING (file still being checked) → NEEDS_REVIEW (file ready) → PRODUCTION_READY (HolyPearls staff).
- **When the new version is approved:** the previous PRODUCTION_READY version becomes SUPERSEDED.
- **Retiring:** PRODUCTION_READY → RETIRED (the organization stops new use).
- **Archiving:** any status → ARCHIVED.
- **Each change** is one service function in one transaction, with an audit entry.
- **PROCESSING → NEEDS_REVIEW** happens when the version's file is READY. Checked whenever versions are read, because the file worker belongs to the files module.

### Permissions

- **Viewing:** any ACTIVE member sees the organization's assets.
- **Uploading, replacing, retiring and archiving:** `MANAGE_BRAND` (Owner and Admin).
- **Staff production review** (mark PRODUCTION_READY, keep in review with a note, retire, archive): `STAFF_ADMIN`. Frame 116 says the permission is "to be decided" and that "until then only STAFF_ADMIN sees it". Recorded under Questions.
- **Downloads:** members of the organization, `ORGANIZATION_SUPPORT` and `STAFF_ADMIN`.
- **Outsiders:** not a member is 404; a member without `MANAGE_BRAND` gets 403 on changes.
