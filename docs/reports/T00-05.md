# T00-05 — Design system foundation

Status: PARTIAL (built and tested; the side-by-side check against the Pen frames is still to do because the Pen MCP was not connected in this session)

Commits / PR: branch `feature/t00-05-design-system`; pull request linked in `docs/tracker/TICKETS.csv`.

What was built:

- **Tokens.** `packages/ui/scripts/build-tokens.mjs` turns `tokens/tokens.json` (the Pen export) into `src/styles/tokens.css`: every `hp-*` variable resolved for the Signal direction, plus the documented spacing scale, type sizes, display tracking, radii, layout widths, 44 px touch target, 2 px focus ring, and motion durations and easings. `hf-*` values (the superseded warm direction) are not emitted. CI fails if the CSS is stale (`tokens:check`).
- **Inferred tokens.** Values the Pen export does not provide are in `src/styles/inferred-tokens.css`, kept apart and listed below for review.
- **Fonts.** Geist and Geist Mono through the `geist` package (self-hosted by `next/font`, no external request).
- **Base styles.** Paper background, Geist 16 px body, visible 2 px focus ring (ink on light, paper on dark surfaces), visually-hidden helper, mono helper and reduced-motion handling.
- **Components** (`packages/ui`): Button (primary, secondary, tertiary, ink, destructive; disabled; loading) and ButtonLink; TextField; Select (native); Checkbox; RadioCardGroup (radio cards in a fieldset); FormField (label, hint, error beside the field, wired with `aria-describedby` and `aria-invalid`); ErrorSummary (takes focus, links move focus to each field); Card (paper, bone, panel); StatusChip (six tones, always with a text label); Dialog (native `<dialog>`, focus kept inside, Escape closes, focus returns to the opener); Toast (polite live region; error toasts stay until dismissed; pauses on hover or focus).
- **Layout shells:** PublicShell, AccountShell, WorkspaceShell and AdminShell, each with a skip link and a focusable `main`. AdminShell is layout only; T00-07 adds staff access control.
- **Page states:** app-wide `not-found.tsx` and `error.tsx`, and PageState and PageLoading components. The loading page sits next to slow routes (demonstrated at `/design-system/states/loading`), not at the app root. See Questions.
- **Demo page:** `/design-system` with every token, component and state, plus shell previews. It is `noindex` and returns 404 in production unless `HP_DESIGN_SYSTEM_DEMO=on`.
- `packages/ui` now ships TypeScript and CSS Modules source, compiled by Next.js (`transpilePackages`), instead of a `tsc` build.

Tests: 54 Playwright tests, run at 375 px and 1440 px (27 checks at each width), all passing locally:

- axe (WCAG 2.0, 2.1 and 2.2 A/AA) is clean on the demo page, all four shells and the loading, error and not-found pages. It is also clean with form errors showing and with the dialog open.
- No horizontal scroll on any of those pages.
- Unknown URLs return HTTP 404 with the not-found page. The error page offers a retry. A slow route shows the loading page first.
- Keyboard: the skip link is first and moves focus to `main`; the error summary takes focus and its links focus each field; the form submits with Enter; radio cards move with arrow keys and skip disabled options; the dialog keeps Tab and Shift+Tab inside, closes on Escape and returns focus.
- Every visible control on the demo page is at least 44 px tall. Body text is Geist at 16 px or more.
