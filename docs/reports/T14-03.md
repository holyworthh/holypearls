## Deviations and conflicts

- **Design deviation: "Pause motion" pill** (not in the Pen), tokens only, on the marquee strip. Page-local, no persistence, `MOTION_BOOT` untouched.
- **Focus ring colour:** DESIGN-SYSTEM line 167 (older section) says ink; Ledger says Holy Blue. Followed Ledger (Q1). The admin ring is now blue, not ink.
- **Results search field (D20):** the Pen shows an always-active ink outline; focus only recolours it to Holy Blue.
- **Plan vs code:** (1) the plan expected one `a11y` walk to find every issue; the 320 px reflow check and D20–D26 were found by it. (2) D7 needed the focus return moved to an effect cleanup (after the dialog is removed), because calling `focus()` while the modal was still open did nothing. (3) The menu test accepts focus reaching the browser (body) at the end of the order, never page content.
- **Local test setup:** `playwright.config.ts` and two e2e files read `E2E_WEB_PORT`/`E2E_ADMIN_PORT` (defaults unchanged) so several checkouts can run at once. This ran on a private Postgres container and ports 3411–3413, not the shared Neon database.

## Suggestions (out of scope)

- Custom `role="radio"` buttons (`PoloPicker`, `StoreViews`, `ParticipantViews`) use Tab and Space; native radios would give arrow keys.
- A persistent live region instead of a `role="status"` Notice mounted with its content; check with a screen reader first.
- An accessibility statement page (the footer links to `/help?topic=accessibility`).
- Not covered: `/preview/content/[token]`, `/collections/submissions/[id]`, admin `/order-drafts/[id]`. Other TECH-08 §11 fixtures (60-person collection, 120-row CSV, ACME logo V4/V5, approval quotes) are still missing.
- Rerun `a11y.spec.ts` after T14-01b and T15-03 (new privacy pages) merge; T14-05 should take its screenshot baseline after this merges (focus ring, pause pill, menu changed).
- CI time grows by roughly 3 minutes per project for the route loops.
